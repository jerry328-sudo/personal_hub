# Personal Hub 模板设计

独立 HTML 原型，无构建依赖。打开 prototype.html 即可使用。所有条目为示例，不连接 API；浏览器本地保存试用操作，可在左下角恢复示例。仓库根目录 index.html 现为真实 React 应用入口。

设计参考：concept.png（内置 Image Gen 生成）。完整提示词方向：中文 Personal Hub 信息收件箱，浅冷灰侧栏、白色列表和阅读区，森林绿强调，固定导航、动态 Agent、标题列表、版本选择、归档与创建待办；不使用统计仪表盘、营销区或装饰图片。

设计系统：背景 #ffffff；侧栏 #f2f5f5；文本 #24352d；次级 #76817c；边框 #e7ece9；强调 #34775e；选中 #edf5f0。系统中文无衬线字体；正文 15px/1.9；控件 13px；文章标题 28px；列表标题 14px。间距 4/8/12/16/24/32/40；圆角 7px。图标使用统一原生 SVG 描边。

组件：App shell、动态侧栏、搜索及筛选、条目列表、版本阅读器、Agent 管理列表、Agent 编辑对话框、待办列表、操作确认对话框、toast。全局收件箱保留三栏信息流；Agent 可以单独选择信息流、清单或报告。清单在原位展开，报告直接展示正文，两者不按日期分组，也没有固定的左侧条目列表。手机使用侧栏抽屉。

行为：新建 Agent 自动进入导航，初始未上报；停用可恢复；移除从日常列表隐藏，历史可搜索；永久删除清除关联条目和版本，待办转入手动记录。已读绑定版本号，旧版本不会把新版标为已读。条目可手动完成或恢复，支持全部、未完成、已完成筛选；完成与已读、归档、待办互不联动。外部 Agent 写入和运行上报由未来 API 提供。

查看新布局：个人信息监控和 AI 动态默认展示报告，论文追踪默认展示清单，微信群通知保留信息流。页面顶部或 Agent 设置中可切换布局，设置中可选择主报告。

外观：侧栏底部提供“夜间模式 / 日间模式 / 随系统”，默认随系统并实时响应系统主题变化。选择单独保存于本机浏览器，刷新和恢复示例数据后保留；手机在导航抽屉中设置。夜间样式覆盖信息流、清单、报告、管理、待办及弹窗，图片保持原色。已离线验证三种模式、系统变化、刷新保存、侧栏重绘及存储不可用时的切换，尚未复核浏览器渲染。

图片：微信群通知示例正文包含一张可放大的图片。“添加示例图片”可以选取不超过 1 MiB 的本地 PNG、JPEG、WebP 或 GIF，在浏览器中追加示例版本，保留原版本及完成状态。模板使用 localStorage，不上传 R2。正式服务的私有 R2、鉴权图片地址、附件元数据和 10 MiB 限制见 ../docs/design.md。

## 初版预览验证

使用 Codex 内置浏览器检查默认 1280×720、设计参考尺寸 1536×1024 与手机 390×844。通过 view_image 查看概念图与实际截图，比较三栏结构、白色/冷灰背景、绿色选中态、文章层级、来源区和工具栏。保留整体视觉方向；实际模板有意采用更紧凑的字号和独立来源/已读/版本行，并明确显示示例数据。首屏功能文案一致；日期不使用可能过期的“今天”，版本未读时提供明确的标记已读按钮。

已通过浏览器验证：新增 Agent、刷新保留、停用、移除并恢复、永久删除后保留待办、搜索及清空、版本切换、未读筛选后的连续阅读、创建及完成待办、手机阅读返回和导航。修复了手机管理行按钮挤压文字，以及未读条目打开后正文被切换的问题。手机页面无横向溢出，浏览器未记录 JavaScript 错误。最终已恢复初始示例。

preview-desktop.png 与 preview-mobile.png 记录初版三栏设计，不包含下面的新增布局。模板尚未接入真实 API、Agent 执行器、数据库或 R2；接入说明仅为未来接口样式。
