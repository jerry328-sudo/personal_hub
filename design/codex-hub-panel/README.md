# Codex Hub 面板交互模板

这是独立前端原型，不连接生产 API/MCP，不包含密钥，不修改真实 Hub 数据。全部内容为示例，操作仅保留在当前页面内；刷新页面或在管理中选择“恢复示例”可重置。

运行 `node design/codex-hub-panel/serve.cjs`，打开 `http://127.0.0.1:4174/`。也可以直接打开 `index.html`；浏览器剪贴板功能在本地 HTTP 预览中更可靠。

## 设计

视觉参考为 `concept.png`，由内置 Image Gen 生成，原始尺寸 1496 × 1051。延续现有 Hub 的白色背景、浅灰列表、森林绿强调、7px 圆角和中文系统字体。采用顶部导航、条目列表、阅读区与底部选中内容托盘。宽度不超过 820px 时，点条目切换到详情，通过“返回列表”返回。

首屏文案、导航、六条示例、主条目正文与操作按钮沿用视觉参考；较窄视口按相同组件体系重排。搜索和筛选、版本阅读、已读、完成、归档/恢复、来源三种布局、待办创建/完成/删除、来源启停及多选引用预览均可操作。

“带入聊天”在模板中打开引用预览，可复制 Markdown 引用。后续正式插件通过 MCP Apps 的宿主接口向当前 Codex 对话传递选中内容，不新增独立聊天框。

## 文件

- `index.html`：面板结构与无障碍入口。
- `style.css`：共享设计变量、组件样式与响应式布局。
- `data.js`：来源、条目版本和待办示例。
- `app.js`：局部状态、列表与阅读器、来源布局、待办及引用预览。
- `serve.cjs`：仅提供模板文件的本地预览服务。
- `concept.png`：视觉参考，保留原始生成文件。

核心概念图提示词：中文 Personal Hub 的完整产品界面；顶部收件箱/来源/待办/归档，左侧六条研究记录，右侧稿件修订正文与版本/已读/完成/归档操作，底部已选内容与带入聊天；真实白色背景、浅灰列表、森林绿强调，无营销区、统计卡片或独立聊天框。

## 验证与参考对照

参考图为内置 Image Gen 生成的 `concept.png`（1496 × 1051），原始生成图已保留在本目录。使用 `view_image` 同时查看参考图与页面截图，逐项比较布局、字体、颜色、正文和底部操作。

| 对照项 | 实现与检查结果 |
| --- | --- |
| 顶部品牌和导航 | 保留图标、Personal Hub、刷新、管理及四个导航；64px 顶栏和 54px 导航栏与参考位置一致。 |
| 列表与阅读区比例 | 宽屏约 34% / 66%；保持同一分割线和阅读顺序，六条示例均可见。 |
| 颜色和组件 | 白色正文、浅灰列表、森林绿选中态、细分隔线及小圆角，保持参考的界面风格。 |
| 标题和正文 | 保留主条目标题、“本轮更新 / 已完成 / 下一步”顺序和正文；版本菜单与操作位于正文上方。 |
| 选中引用托盘 | 固定在底部，保留条数、标题、带入聊天与清空；导航和阅读时保持选择。 |
| 字体与文本密度 | 修复中文字体回退造成的衬线字形，优先 Noto Sans SC / 微软雅黑；调整宽屏条目间距，修复第六条摘要截断。 |

有意差异：参考图的文字为生成图像；模板使用真实可选中文文本和系统字体，字距、字形与行宽会随设备略有变化。列表元信息统一用 `·` 分隔，超出可用宽度的摘要显示省略号。窄面板改为列表 / 详情切换，正文可滚动，选中托盘保持可见。

交互检查通过 Codex 内置浏览器完成：搜索、多选引用预览、历史版本、已读、创建及完成待办、归档及恢复、来源的清单 / 信息流 / 报告切换、恢复示例。内置浏览器的截图接口在本次环境无法捕获画面，改用现有 Chrome 的无界面实例及已有 Playwright 库截图，没有安装额外软件。

1496 × 1051、620 × 880、390 × 844 三个视口均无水平溢出，页面运行错误为零。截图为 `preview-wide.jpg`、`preview-panel.jpg`、`preview-detail.jpg`、`preview-mobile.jpg`。仅截图与交互原型已经验证；生产 API、MCP 和 Codex 对话桥接尚未接入。
