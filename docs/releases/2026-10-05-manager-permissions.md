# 总管完整管理权限升级

状态：已按用户批准部署至生产，并完成线上验证。

生产地址：`https://personal-hub.echem.ai`。Worker 版本：`3b74acc8-e2fb-4fe5-b6ba-eb0ed8379308`。

## 升级后的行为

- 所有启用的总管身份及其现有有效密钥都获得完整管理权限，不需要重新签发密钥，也不需要数据库迁移。
- 总管 Bearer Key 可以调用现有 `/api/v1/admin` 管理接口；原 `/api/v1/manager` 接口继续可用，并新增待办删除。
- 开放条目已读、归档、完成和永久删除，跨来源待办删除，Agent 创建、配置、启停、移除、恢复和分步永久删除，密钥签发和撤销，只读来源授权，通行密钥查看和撤销，管理员登录密钥修改，以及 MCP OAuth 授权查看和撤销。
- 修改管理员登录密钥仍须验证当前登录密钥。Cookie 登录、退出及设备通行密钥注册使用原网页流程。
- MCP 直接密钥连接获得完整工具列表；OAuth 总管连接可显式批准 `hub:admin`，已有授权不会自动扩展批准范围。
- 停用、到期和撤销继续生效。普通和只读身份保持原权限。版本、附件与来源授权日志保留总管操作者编号。
- 管理员 Cookie 写操作继续要求同源；总管 Bearer 管理请求可无 Origin，携带 Origin 时必须同源。
