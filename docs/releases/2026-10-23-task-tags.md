# 待办多标签发布

2026-10-23 已部署生产。代码提交 `ece3a012f19579f85ba556d0c3f335ddff6526c0`，Worker 版本 `e73af482-0766-480a-8fb1-290aabade23d`，上一版本 `43d1fece-eebf-4a17-9558-c7f541ad035a`。发布命令为 `npm run deploy:production`。

## 功能

- 网页和 MCP 面板支持新建待办时多选标签、已有待办增删标签、全局标签新增 / 重命名 / 删除，以及标签 / 无标签筛选。
- 标签目录仅管理员和总管可管理；普通 Agent 可给自己的待办使用已有标签。只读身份仅能读取授权待办涉及的标签。
- 删除标签只删除关联；待办及其他标签保留。
- REST API、MCP tools、角色工具清单、线上 API 文档及[使用说明](../task-tags.md)同步更新。
- 清除已完成待办同时遵循来源和标签范围。计数只包含待办，排除级联删除的关联行。
- 提交同时收录此前已上线但未提交的紧凑面板和 OAuth 回调来源策略修复。
