# Personal Hub 插件

私有插件包连接现有 `https://personal-hub.echem.ai/mcp`，不包含密钥或业务数据。面板由该 MCP 服务返回的自包含 HTML 资源提供，无需额外网站或独立聊天框。

安装后连接 Personal Hub，在本站 OAuth 授权页选择“使用已有 Agent 密钥授权”，填写现有总管密钥，勾选 `hub:admin`；需要保持连接时同时选择 `offline_access`。密钥只提交到 Personal Hub，宿主得到独立 OAuth token。现有只读或普通来源身份仍可使用对应权限的面板。

连接成功后从导航或当前聊天的内容面板入口打开 Personal Hub，也可以在聊天中说“打开我的 Hub 面板”。插件技能 `hub` 支持直接读取、整理和按明确指令管理 Hub。

点击“带入聊天”会展示完整引用，点击“附到聊天”后将记录附到当前对话的草稿上下文；不会自动发送消息。条目 ID 与版本固定，附上前会重新检查授权。用户在宿主移除引用后，面板会更新附件状态。

总管面板提供条目已读、完成、归档恢复、待办创建完成删除、来源显示模式及启停。其他管理操作通过现有 MCP 工具按请求执行。身份及 scope 决定可见按钮，服务端每次调用都重新核验权限。永久删除待办要求在面板明确确认。
