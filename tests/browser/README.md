# 浏览器回归测试

运行 `npm run dev`，打开开发服务的 `/tests/browser/read-access.html`，点击“运行回归测试”。

页面使用生产 React 组件和浏览器 DOM，模拟读取响应的顺序、失败与重试，不连接后端或修改权限。覆盖跨 Agent 迟到响应、加载失败禁止保存、失败重试，以及关闭后重开同一 Agent。结果显示“3 项通过”才算成功。

该页面不包含在生产构建中；`npm test` 运行的是独立的 Worker 测试，不包含此浏览器检查。

## Codex Hub 面板

先运行 `npm run build:panel`，再运行 `npm run panel:preview`。独立测试宿主在 `http://127.0.0.1:4175/` 加载正式自包含面板，使用 MCP Apps SDK 模拟宿主与业务工具；不连接生产环境。

安装了 Playwright 的环境可运行 `npm run panel:check`，或用 `PANEL_PLAYWRIGHT_MODULE` 指向已有 Playwright 模块。使用已有 Chrome 的无界面实例，覆盖游标末页、历史引用附件、保留草稿、宿主移除引用、条目关联待办来源、完成筛选、归档恢复、信息流 / 清单 / 主报告、明暗主题及只读连接。面板通过严格 CSP 禁止外部连接和 `unsafe-eval`。

检查 1920 × 980、1496 × 1051、620 × 880、390 × 844 和 620 × 360 面板；外层测试宿主额外占 100px 高度。新增检查覆盖默认三项未完成待办（模拟迁移已删除 21 项归档关联记录）、已完成 / 全部 / 来源筛选、搜索、夜间悬停标题与次要文字对比度、宽屏列表上限、宿主尺寸变化与底部安全留白，以及图标解码。截图默认保存在系统临时目录 `personal-hub-panel-qa`，可用 `PANEL_QA_OUTPUT` 指定外部输出目录。此测试不证明新版图标和布局已在实际 Codex 宿主生效。
